# MarketingTeam — Indie iOS App Marketing AI Takımı

Bu klasör, App Store'da uygulamaları olan bir indie iOS developer için **kendi başına yaşayan bir AI marketing ekibidir**. 14 uzman ajan + 13 user-invocable skill + derinlemesine bilgi bankası.

> **Öncelik sırası**: PAID UA (Meta / TikTok / ASA / Google) > Content production > ASO

## Bu klasörde ne var?

| Klasör | Ne içerir |
|---|---|
| `.claude/agents/` | 14 uzman ajan (hepsi `mt-` prefix'li) |
| `.claude/skills/` | 13 user-invocable skill (hepsi `mt-` prefix'li) |
| `agent-rehberi/` | Her ajan için "ne / neden / ne zaman / nasıl" rehberi |
| `skill-rehberi/` | Her skill için detaylı kullanıcı rehberi |
| `bilgi-bankasi/` | Konu konu derinlemesine MD bilgi tabanı |
| `projects/` | Senin uygulamaların (her birine bir klasör) |
| `entegrasyonlar/` | API/MCP kurulum durumu & config |
| `hesap-kurulumlari/` | Reklam platformlarına kayıt süreci takibi |
| `butce/` | Aylık bütçe takibi |
| `raporlar/` | Haftalık / aylık performans raporları |
| `icerik-takvimi/` | Content marketing takvimi |
