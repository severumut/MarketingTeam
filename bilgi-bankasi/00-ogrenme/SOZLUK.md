# Marketing Sözlüğü

> Öğrenme sürecinde karşılaşılan terimler — hangi modülde öğrenildi, kısa tanım.

---

## Modül 1 — Temeller

| Terim | Açıklama |
|---|---|
| **UA** (User Acquisition) | Kullanıcı edinme — genel çatı terim. Alt türleri: Paid UA (para vererek), Organik (viral/sosyal), ASO (App Store araması). |
| **ASO** (App Store Optimization) | App Store içinde keşfedilebilirlik; title, subtitle, keywords, screenshot optimizasyonu. |
| **Organik Content** | Sosyal medya / viral içerik üretimi. Sistemde kapsam dışı (zaman kısıtı). |
| **Install** | Reklamdan veya aramadan gelen kullanıcının uygulamayı indirmesi. |
| **Scale** | İşe yarayan kampanyayı büyütmek — bütçeyi artırmak. |
| **Churn** | Kullanıcı kaybı; uygulamayı indirip sonra bırakan kullanıcılar. |
| **Freemium** | Ücretsiz temel özellik + ücretli premium; kullanıcı dener, beğenirse öder. |
| **IAP** (In-App Purchase) | Uygulama içi satın alma; hint paketi, extra level, özellik kilidi açma. |

---

## Modül 2 — Funnel ve Metrikler

| Terim | Açıklama |
|---|---|
| **Funnel** | Kullanıcının "reklamı görme"den "para ödeme"ye giden yolculuğu. Her adımda kullanıcı düşer. |
| **CPM** (Cost Per Mille) | 1000 reklam gösterimi için ödenen para. Kitleye ucuza ulaşma göstergesi. |
| **CTR** (Click Through Rate) | Reklamı görenlerin kaçının tıkladığı. Düşükse creative zayıf sinyali. |
| **CPI** (Cost Per Install) | Bir install için ödenen para. Düşük CPI tek başına iyi değil — kalite de önemli. |
| **CR** (Conversion Rate) | Reklama tıklayanların kaçının install ettiği. Düşükse App Store sayfası zayıf. |
| **D1 / D7 / D30 Retention** | 1. / 7. / 30. gün hâlâ kullanan kullanıcı oranı. IAP + Ads app'lerde en kritik metrik. |
| **LTV** (Lifetime Value) | Bir kullanıcının ömrü boyunca getirdiği ortalama gelir. En az 90 gün veri gerekir. |
| **ARPU** (Average Revenue Per User) | Kullanıcı başına ortalama aylık gelir. Toplam Gelir ÷ Aktif Kullanıcı. |
| **ROAS** (Return on Ad Spend) | Reklama harcanan $1 için geri alınan para. Zaman eksenine göre değişir (D7 vs D30). |
| **Payback Period** | Kullanıcı edinme maliyetini karşılama süresi. CPI ÷ Aylık ARPU. |
