# bilgi-bankasi/ — Konu Konu Derinlemesine MD Bilgi Tabanı

Bu klasör marketing'in tüm alanlarını konu-konu anlatan referans dokümanlardan oluşur. Ajanlar bu klasörü hem **kaynak** olarak kullanır, hem de zamanla **büyütür**.

## Klasör organizasyonu (öncelik sıralı)

| Klasör | İçerik |
|---|---|
| [01-temeller/](01-temeller/) | Temel kavramlar — app marketing nedir, funnel, metrikler, attribution |
| [02-paid-ua/](02-paid-ua/) | **Ana ağırlık** — Meta / TikTok / ASA / Google rehberleri, kampanya yapılanması, bidding, scaling |
| [03-content/](03-content/) | Trend research, viral hook library, kategori-bazlı creative referansları (`mt-creative-yonetmeni` Mod E için) |
| [04-aso/](04-aso/) | ASO temelleri ve ince ayar (kullanıcı zaten temelleri yapıyor) |
| [05-attribution-ios/](05-attribution-ios/) | iOS attribution, ATT, SKAdNetwork, AEM, MMP'ler |
| [06-monetization/](06-monetization/) | Subscription, IAP, paywall, RevenueCat |
| [07-araclar/](07-araclar/) | App Store Connect, MMP'ler, analytics, ASO ve creative araçları |
| [08-entegrasyonlar/](08-entegrasyonlar/) | API'ler — Meta Marketing, TikTok Business, ASA, Google Ads, MCP'ler |
| [09-playbooklar/](09-playbooklar/) | Uçtan uca senaryo rehberleri — playbook'lar |

## Phase 3'te derinleştirilecek

> ⚠️ Phase 0 sonu: Bu klasör henüz iskelet. Klasörler ve README'leri var ama içerik MD'leri Phase 3'te yazılacak.
