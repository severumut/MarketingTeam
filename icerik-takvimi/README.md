# icerik-takvimi/ — Content Marketing Takvimi

Organik içerik üretimi (TikTok / Reels / Shorts / X) takvimleri. `mt-content-uretici` + `/mt-content-takvimi` skill'i bu klasörü kullanır.

## Klasör yapısı

```
icerik-takvimi/
├── README.md                       ← Bu dosya
├── _sablon/                        ← Aylık takvim şablonu
└── <yyyy-mm>.md                    ← Ay bazlı takvim
```

## Yeni takvim oluşturmak için

```
/mt-content-takvimi
```

(Phase 2'de yazılacak.) `mt-content-uretici` ajanı:
1. Hangi uygulama / hangi hedef kitle sorar
2. 2 veya 4 haftalık post takvimi hazırlar
3. Her gün için: format (TikTok / Reels / Shorts / X), tema, hook, içerik notu
4. UGC creator'larla ayrı brief'ler

## Format örneği

```markdown
# 2026-05 — Mayıs İçerik Takvimi

## Hedef
- App: <app-adi>
- Kitle: <persona>
- Hedef metrik: Reach + organik install

## Hafta 1
- Pzt — TikTok: "X problemi var mı?" hook + 15sn demo
- Çar — Reels: Before/after dönüşüm
- Cum — Shorts: 30sn quick tip
- ...
```
